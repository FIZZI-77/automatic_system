# Asset Service

Формат QR-кодов для физических объектов и правила их проверки описаны в
[документе проекта](../docs/asset-qr-codes.md).

Реестр городской инфраструктуры на PostGIS: карточки и геометрия объектов, состояния, инциденты, ремонты, осмотры и планы обслуживания. После эксплуатационных событий рассчитывает объяснимый риск поломки на 90 дней и публикует `assets.events.v1` через transactional outbox.
